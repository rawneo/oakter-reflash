Teach the blaster each button from the original remote, then test it. Codes are saved on the web server and sent through the OakRemote.

checking blaster…
To learn a button
  1. Tap Learn on the card.
  2. Within 20 seconds, point the original remote at the blaster (about 30 cm) and press that button once.
  3. The card turns green when the code is captured. Tap Test to send it.
Learned codes are stored by oak.php (see STORE there).
